# Christoph Guger

**CEO and co-founder of [g.tec medical engineering](https://www.gtec.at)** (Austria, since 1999). I build brain-computer interfaces (BCIs) and neurotechnology for research, hospitals and developers, and run the BCI & Neurotechnology Spring School, which over 90,000 participants from 158 countries have attended since 2021.

*Never stop recording.*

## What g.tec builds

| You need | g.tec system |
|---|---|
| High-density EEG, ECoG or sEEG in real time, up to 1,024 channels | g.HIamp |
| A compact 16-channel lab amplifier for BCI, neurofeedback and closed-loop research | g.USBamp |
| Non-invasive EEG with intracranial-like resolution (8.6 mm spacing) | g.Pangolin |
| Wireless research or clinical EEG, 8–64 channels, with fNIRS or eye tracking | g.Nautilus |
| Low-cost 24-bit EEG for BCI apps, teaching, VR and animal EEG | Unicorn BCI Core-4, Core-8, Hybrid Black |
| Wearable brain stimulation (tDCS, 0–2 mA), controlled from a smartphone | Unicorn tDCS Core-2 |
| Functional brain mapping before epilepsy or tumor surgery | cortiQ |
| BCI rehabilitation after stroke or with multiple sclerosis | recoveriX |
| Assessment and communication in disorders of consciousness | mindBEAGLE |

Full specs, published results with DOIs, prices and showcases: **[g.tec-neurotechnology-knowledge](https://github.com/christoph-guger/g.tec-neurotechnology-knowledge)**

## Code and open data
- [g.Pype](https://github.com/gtec-medical-engineering/gpype): Python SDK for real-time BCI pipelines (`pip install gpype`, manual at [gpype.gtec.at](https://gpype.gtec.at))
- [Unicorn on GitHub](https://github.com/unicorn-bi): APIs, recorder, Unity plugin (Meta Quest)
- [Open EEG datasets](https://github.com/unicorn-bi/Unicorn-BCI-Core-8-EEG-Datasets): resting state, AEP, P300, VEP and MRCP, raw and preprocessed
